# Brick Breaker Demo

一个纯前端的霓虹街机风「弹珠打砖块」游戏 Demo。无需安装依赖、无需后台，直接打开 `index.html` 即可游玩。

## 运行

```bash
# 方式一：直接打开
open index.html

# 方式二：本地静态服务器
python3 -m http.server 4173
# 浏览器访问 http://127.0.0.1:4173
```

## 操作

- **背景音乐**：进入页面后，在浏览器允许的首次交互时播放一段循环的未来电子音乐；右上角声音按钮可同时静音音乐与音效。
- **鼠标**：移动鼠标控制反弹板。游戏正式开始后会启用 Pointer Lock 锁定鼠标，光标无法移出游戏窗口，并改为按相对移动量操控反弹板；准备状态、暂停中、胜利或失败结算时会自动释放锁定。
- **键盘**：按 `A` 向左、`D` 向右移动反弹板；鼠标一动会立即切回鼠标操控。
- **发射**：点击「游戏开始」进入准备状态；弹珠停在反弹板中央时，点击鼠标左键或按 `空格键` 从正上方发射。
- **暂停**：游戏中按 `Esc` 暂停 / 继续；鼠标移出游戏区域会自动暂停。
- **暂停菜单**：可以继续游戏、调整键盘移速，或放弃本局返回开始页；放弃不会写入排行榜。
- 反弹板的反弹角度同时受「接触位置」和「反弹板横向移动速度」影响。
- 弹珠全部坠落则失败；清空全部砖块则通关。

## 本局配置

进入游戏前可以设置玩家名字、三项独立难度，以及独立的键盘移速。玩家名字在每次打开或刷新页面时从 100 个常见英文名中随机填入；名字输入框右侧的骰子按钮可再随机换一个名字。同一次页面会话中返回开始页会保留当前名字，刷新或重新进入则重新随机。

开始页的五档设置均采用可拖动的横向滑轨展示：每个档位是轴上的一个节点，支持拖动、点击节点以及方向键切换。滑轨只显示档位名称，不显示具体数值；节点排列顺序、内部数值和奖励积分倍率均与之前保持一致。

| 档位 | 球速 | 砖块总耐久 | 奖励砖块占比 |
| --- | --- | --- | --- |
| 1 | 悠闲 | 170 HP | 50%（最多） |
| 2 | 轻松 | 215 HP | 40% |
| 3 | 适中 | 260 HP | 30% |
| 4 | 挑战 | 305 HP | 20% |
| 5 | 极限 | 350 HP | 10%（最少） |

球速档位为 `300 / 370 / 480 / 610 / 745 px/s`，其中第 3 档对应之前版本的第 2 档。

奖励砖占比按本局实际砖块数计算。界面排版为**左少右多**：最左侧是第五档（10%），最右侧是第一档（50%）；档位编号和结算倍率不随 UI 顺序变化。第一档仍为 `×1.0`，第五档仍为 `×2.0`。

砖块总耐久度始终精确等于所选值。砖块耐久按高度分布：越靠上的砖块整体越耐打，偏下的两排砖块耐久度保持在 1~3。每局至少 30% 的奖励砖块会被安排在砖块区域偏下 30% 的范围内。

砖块排列更窄、更紧凑：采用 12 列 × 7 排窄砖，水平缝缩小到 3px、垂直缝缩小到 6px，共 71 块砖。左右随机偏置的阶梯式刻意空档保留为 13 个空位 / 84 个格位（约 15.5%，此前为 11/70，约 15.7%），弹珠仍可沿这些通道连续反弹。

键盘移速可独立设置为 5 档：`460 / 620 / 800 / 1020 / 1240 px/s`。该设置只改变 A / D 键的操控手感，不参与难度计算，也不影响最终结算积分。开始页和暂停菜单都可以随时调整。

## 计分与结算

- 每消耗 1 点砖块耐久获得 `100` 分。
- 击碎原始耐久大于 1 的砖块时，最后那一次碰撞的分数会按原始耐久提高：
  - 原始耐久 2：`110%`
  - 原始耐久 10：`190%`
  - 中间档位线性递增。
- 结算加成全部以**原始基础分**为基数相加，不进行倍率连乘：
  - 最终分 = 原始基础分 × `[100% + 球速加成 + 奖励砖加成 + 通关时间加成]`
  - 球速加成：1 档 `+0%` → 5 档 `+100%`
  - 奖励砖加成：1 档 `+0%` → 5 档 `+100%`
  - 通关时间加成：60 秒内通关 `+100%`；60～180 秒线性下降；180 秒及以上 `+0%`
  - 失败结算不计算通关时间加成。
  - 砖块总耐久不参与加成。
- 示例：原始分 `10000`，同时有 `+50%` 与 `+100%` 两项加成，最终分为 `10000 × (100% + 50% + 100%) = 25000`，不是连乘。
- 成功和失败都会进入结算并记录排行榜。

## 砖块与道具

- **奖励砖块**：金色流光、滚动虚线描边、星标与闪烁粒子。击碎后从原位置掉落一个随机道具。
- **道具**（游戏内类型标识已改为中文）：
  - **分裂（A）**：每颗场上弹珠随机分裂为对应数量的弹珠，掉落物上会显示 `×N`。
  - **加长（B）**：每次使反弹板加长 `52.5px`，上限为游戏区域宽度的 50%；拾取 8 次即可达到最大长度。
  - **穿透（C）**：10 秒内，弹珠击碎砖块后不反弹，沿原轨迹继续运动。
  - **强化（D）**：拾取后弹珠威力在当前基础上 +1，效果持续到本局结束；之后碰砖不会再自动成长。重复拾取会继续叠加 1 点当前威力。D 本身不会让弹珠穿透砖块；只有 C 可以让弹珠在击碎砖块后继续前进。
  - **无敌（E）**：5 秒内，反弹板扩展为游戏区域 100% 宽度。期间拾取的 **加长** 会储存，在 **无敌** 结束后生效。
- `C` 与 `D` 可以同时生效。HUD 中的 `POWER` 会显示当前弹珠威力。
- 限时道具（穿透 / 无敌）生效期间再次拾取同类道具会**重置该效果的持续时间**；无敌会保留已储存的加长。
- 画面下方会显示当前生效的限时增幅道具、剩余秒数与实时进度条，类型标识同样使用中文。

## 本地排行榜

- 开始页底部提供整块全宽排行榜，固定展示 10 行，完整显示名次、玩家、难度配置、用时和结算积分；超过 10 条时列表内部滚动。
- 排行榜高度增加后，如果当前窗口无法同时容纳配置区与 10 行排行，首页内容区支持纵向滚动；滚动到排行榜即可一次查看完整的 10 条记录。
- 每局成功或失败结算后，会把玩家名字、最终积分、时间及难度写入浏览器 `localStorage`。
- 默认展示成功通关的记录；切换「全部记录」会同时展示成功与失败记录。
- 列表按结算积分从高到低排序，超出可视区域可滚动查看。
- 首页最底部提供「删除本地排行榜」按钮；删除前会弹出二次确认，确认后会清空当前浏览器保存的全部战绩与积分，操作不可撤销。
- 排行榜只保存在当前浏览器，不会上传到任何服务器。
